UN POCO SOBRE EL SITIO

Una página hecha paso a paso

La idea de este proyecto es practicar la estructura de HTML5 y darle estilo con CSS3. Elegí una temática relacionada con el diseño web porque permite combinar imágenes, texto, video y efectos sin recargar demasiado la página.

LO QUE ESTOY PRACTICANDO

Tres partes importantes

Estructura HTML

Ordenar el contenido con etiquetas semánticas como header, nav, main, section y footer.

Estilos CSS

Usar colores, espacios, clases e identificadores para mantener una presentación ordenada.

Contenido multimedia

Agregar recursos de audio y video, cuidando que se puedan ver desde distintos dispositivos.
